## 7. Refinements — typed and addressed

Every row is one file and one invariant. **`invariant` is the grep pattern; `all instances` is that
grep's output.** A row naming an instance with no invariant reaches the instance and not the class —
that has happened five times in the seeded corpus and is the single most expensive habit here.

| name | file it changes | what to change | why | expected saving | risk | prior runs raising it | invariant | all instances |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

- **`file it changes` names ONE file.** If you cannot name the file, you have not found the cause.
- **`expected saving` is directional and honest.** "Removes one full-suite run per review round" beats
  an invented percentage. `unquantified` is a valid value; a fabricated number is not.
- **`risk` is mandatory.** A change with no downside listed has not been thought through.
- **`all instances` must be exhaustive or say `grep <pattern> → n hits, all listed`.** An ellipsis here
  is the defect this column exists to prevent.
- **Landing order.** Scoped commits, suite between, stop at the first red — unless routed through the
  supervisor-changeset pattern (`proposals/README.md`). Say which applies.
